# 离线试算表工作台

从空仓库建立的**纯前端**工作台：TypeScript + React + Vite，由 Docker Compose
运行 `web` 服务。无后端、无外部 API、无第三方解析库；所有计算在浏览器本地完成。

## 运行

```bash
docker compose up --build
# 打开 http://localhost:5173
```

本地开发（无 Docker 时）：

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # Vitest，30+ 用例
npm run build    # 类型检查 + 生产构建
```

> 只有 `npm install` / 镜像构建阶段需要拉取依赖；应用运行期不访问网络。

## 网格规则

- 网格固定 **20 列（A..T）× 20 行（1..20）**。
- 每格为：**空**、**整数**（允许前导负号，无 `+`/前导零）、或以 `=` 开头的**公式**。
- 公式白名单：整数字面量、`A1..T20` 引用（大小写不敏感）、括号、一元负号、
  `+ - * /`。**没有函数、没有范围（`A1:A3`）、没有空白、没有小数点**，
  任何其他字符都会被解析器拒绝。
- 求值使用自行实现的递归下降解析器与**约分 BigInt 分数**，不存在浮点误差
  （`1/3+1/3*2` 严格等于 `1`）；空引用按 `0` 参与运算。
- 十进制显示（如 `0.3333…`）仅为质检员的辅助近似，真正的结果永远是精确分数。

## 重新计算语义（核心）

- 自行维护**依赖图与反向边**。编辑一格后，只重算该格与其**传递下游**
  （Kahn 拓扑序），其他格保持原值。
- **循环引用**：对受影响子图做 Tarjan SCC，标出**实际环**（如
  `A1 → B2 → A1`，含自环）；环上每个成员显示 `↻ 循环` 并给出环路径。
- **下游传播**：环外依赖环的格、除零/非法公式的下游格，全部标记为错误并
  显示从源头到当前格的**传播路径**；它们**绝不显示旧数值**。
- **除零**：在执行 `/` 前判定约分后的除数是否为 0；源头与下游都可追溯。
- **编辑后恢复**：修复源头（改成常量、删除依赖边、清空等）后，下游逐级
  立即恢复为精确分数。

## 导入 / 导出

- 工具栏“导入网格 JSON”接受：
  ```json
  { "cells": { "A1": "2", "A2": "=A1*3" } }
  ```
  也接受导出文件中的 `{ "raw": "..." }` 条目形态。
- 导入先**整体校验**（地址必须在 A1..T20、值必须是字符串或 `{raw}`、
  每个公式都能解析）。**任何一格非法即拒绝整份网格，当前（上次有效）表保持
  不变**，并列出前 20 条原因。
- “导出当前快照 JSON”下载的就是界面表格使用的**同一份计算快照**
  （`sheet.snapshot()`），含每格原文、直接依赖/下游、精确分数、十进制辅助
  与错误（环路径/传播链）。

## 质检员如何解释每个数值

选中任意格，右侧面板展示：

1. **原始内容/公式** 与编辑栏；
2. **精确分数**（分子/分母）与十进制近似；
3. 错误时的**实际环**或**错误路径**（可点击的格跳转）；
4. **直接依赖**与**直接下游**；
5. **数值来源解释树**：把公式 AST 逐步展开，每个中间节点都标注其精确分数，
   沿引用可继续向内展开，因此任何数字都能追溯到输入的整数常量。

## 目录

```
src/engine/address.ts    A1..T20 寻址
src/engine/fraction.ts   BigInt 约分分数与四则运算
src/engine/parser.ts     手写递归下降解析器 + 引用白名单
src/engine/classify.ts   空 / 整数 / 公式 分类
src/engine/sheet.ts      依赖图、增量重算、SCC 环检测、导入校验、快照
src/engine/explain.ts    逐步推导解释树
src/ui/                  React 网格与检查器
tests/                   Vitest：优先级、负号、环、传播、恢复、导入
```
